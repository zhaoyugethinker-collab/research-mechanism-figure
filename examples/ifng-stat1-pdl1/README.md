# 第二期：IFN-γ/STAT1/IRF1→PD-L1 亚细胞机制图

对应文章题目：**如何使用GPT和Codex画亚细胞级机制图？**

## 复跑入口

1. 先看[机制关系表](mechanism-relations.md)及[来源](sources.md)，按实际用途核对并确认科学关系。
2. 使用[结构图](structure-guide.png)和[风格卡](style-guide.png)作为两个不同角色的参考。可编辑粗结构源稿为[structure.drawio](structure.drawio)，精确布局记录为[layout.json](layout.json)。实际B输入是两张PNG，draw.io导出局部连线靠近标签，不应当作最终精细图。
3. 附上两张PNG，将[精确B提示词](prompts/B_controlled.txt)发给图像工具，保存第一轮结果。实际调用入口为内置image_gen；未暴露精确模型、seed或费用。
4. 按[12项规则与评分说明](review-rubric.md)逐项检查。根据自己的实图使用[通用修正模板](../../prompts/targeted-edit.md)，而不是直接假定出现了B1的错误。
5. 若要原生PPT，使用[重绘指令](../../prompts/native-ppt-redraw.md)，执行结构与GUI两类检查。

本目录提供原始输入，便于复用流程；随机生成无法保证逐像素复现。当前发布不包含最终精细PNG、PPTX或编辑截图的二进制文件，避免把输入资源包误当成已授权复用的成品画库。

## 已做测试与失败

| 路线 | 次数 | 实际观察 |
|---|---:|---|
| A：完整机制文本直接生成 | 3 | 已有较强视觉质感；仍有RNA出核方向/连续性或线型问题 |
| B：完整文本＋原创结构图＋风格卡 | 3 | 本次三图布局较一致；不保证机制正确，B2把RNA画进分泌囊泡 |
| C：分别对三个B输出编辑一轮 | 3 | C1、C2改善；C3未补好RNA输出连线且新增反向箭头，淘汰 |

A/B/C共9次调用。C为B的配对编辑，不是9个独立样本。A并非弱提示词；B增加了整个控制包，不能把差异只归因于草图。C平均质量提高，但本次波动更大，不支持“多改几轮必然更好”。所有精确提示词都在[prompts/](prompts/)，包括失败C3。

原生PPT另按C1重绘一张，未作为第4路线重复测试。最终为775个原生叶对象、19个原生组合、30个文本框、264个自由形状、0图片对象。类别重叠，不相加。已在PowerPoint副本中改字、移动IRF1与细胞核、调整箭头，保存关闭重开后保留修改；已核对XML变化。用户另外提供了多对象选中截图。光影与纹理为矢量近似；箭头原生组合不自动吸附节点。

上述为2026-10-14至15日单案例实做记录，由当前Codex非盲评审，未作独立领域专家审稿。技能自动发现、跨产品复现、无限修正可靠性均未验证。本目录不是通用医学结论。
