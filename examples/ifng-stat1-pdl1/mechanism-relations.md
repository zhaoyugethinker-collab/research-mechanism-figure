# 冻结机制关系表

场景：对 IFN-γ 有反应的肿瘤细胞，经典 IFN-γ/JAK/STAT1/IRF1 轴。不是所有肿瘤、所有条件的唯一调控通路。

| 起点 → 终点 | 分区 | 关系/图线 | 来源/简化 |
|---|---|---|---|
| IFN-γ → IFNGR1/IFNGR2 复合体 | 胞外→质膜 | 结合，实线 | S1、S2；受体亚基数不按真实计量绘制 |
| IFNGR1—JAK1；IFNGR2—JAK2 | 胞质侧膜下 | 关联定位 | S2；必须对应，不倒置 |
| 激活的 JAK → STAT1 Y701 磷酸化 | 胞质 | 激活，实线 | S3；省略受体磷酸化/招募细节 |
| p-STAT1 → 同二聚体 | 胞质 | 二聚化，实线 | S4；用两亚基示意 |
| p-STAT1 二聚体 → 核内 | 胞质→核孔→核 | 向内实线 | S3、S4、S5 |
| 核内 p-STAT1 → IRF1 induction | 核 | 上调表达，实线 | S1、S5；IRF1 转录/翻译/回核中间步骤省略，不是蛋白转化 |
| IRF1 → CD274 转录 | 核内 DNA | 调控，实线 | S1；CD274 为 PD-L1 编码基因 |
| CD274 → CD274 mRNA → 核外 | 核→胞质 | 转录与输出，实线 | 通用转录/输出示意；非 S1 运输实验结论 |
| 核外 mRNA → 膜 PD-L1 ↑ | 胞质→质膜 | 虚线：Translation + trafficking | 教学简化；概括翻译及 ER/Golgi 蛋白分泌运输；不表示 RNA 装入分泌囊泡 |

背景细胞器：淡色 ER/Golgi、可选线粒体，仅作空间解剖背景。不能对其新增因果箭头。终点止于膜 PD-L1 表达，不添加 PD-1、T 细胞抑制、治疗响应或定量变化。↑ 为定性上调，不代表实验效应大小。
