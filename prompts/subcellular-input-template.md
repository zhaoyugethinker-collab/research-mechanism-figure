# 换题输入模板

以下花括号是明确供填写的模板字段，不是未完成的本例结果。

- 主题：{一句话}
- 生物学场景/适用条件：{物种、细胞、刺激或实验条件}
- 证据来源：{题名、DOI/PMID、支持的具体关系}
- 主线：{起点→中间步骤→终点}
- 分区：{胞外/细胞膜/胞质/核/参与的细胞器}
- 节点：{正式名称、类型、分区、必须出现的状态如磷酸化}
- 关系表：{起点、终点、结合/激活/抑制/转位/转录/运输、证据、线型}
- 不能省略：{否则会改变含义的步骤}
- 明确简化：{被合并的多步关系及图例解释}
- 禁止添加：{相关但不在本图范围的支路、疗效、表型、其他细胞}
- 布局：{读图顺序、各分区位置、入口与出口的位置}
- 风格：{背景、配色、空间感、对比、标签语言}
- 交付用途与尺寸：{公众号/汇报；宽高比例；主图或局部放大图}

## 通用生成指令

请依据已核对的关系表绘制一张原创细胞内部机制图。图1只作结构参考，图2只作风格参考。将流程框转成清楚的生物学符号，用半剖视角呈现膜、胞质和核。严格执行分区与箭头方向；证据表优先于草图中不精确的几何位置。背景细胞器保持低对比，只有关系表明确支持时才连接因果箭头。精确保留正式分子名称。用图例说明所有简化和线型。不得增加未经证据支持的支路或治疗结论。

将上面的已填字段与关系表完整附后，再生成，不留占位字段。

## 通用定向修正指令

以附图为唯一编辑目标。保留已正确的细胞轮廓、分区、配色、分子位置、标签和关系。

只修正：
1. {位置/对象}：当前{具体问题}；应为{正确目标及方向}。
2. {位置/对象}：当前{具体问题}；应为{正确目标及方向}。

禁止新增{支路/元素}。修改后检查全部关键关系是否仍正确，尤其检查进入核与离开核的箭头、RNA与蛋白的区别、实线/虚线语义。若无法局部完成，请报告问题而不是扩写机制。
