# Scientific boundaries

- **Source integrity:** Never invent citations, identifiers, findings, or source locations. If a paper is inaccessible, say so and work only from the text provided by the user.
- **Evidence level:** Attribute each edge to its evidence. Keep association, correlation, temporal order, proposed mechanism, and demonstrated causation distinct.
- **Uncertainty:** Mark ambiguous direction, context dependence, conflicting evidence, and unsupported claims. Do not resolve them by model preference.
- **Scope:** Use the minimal mechanism that answers the requested figure question. Omit out-of-scope branches and explain consequential omissions.
- **Human review:** The scientific relationship table must be confirmed before image generation. Confirmation applies only to the displayed version; later material changes require review again.
- **Image status:** A polished illustration is not evidence. Label conceptual diagrams; do not present them as experiments, measurements, or quantitative findings.
- **PPT status:** “Editable” describes tested objects, not the file extension. A single PNG in a slide is not a fully editable figure. Disclose conversion tool provenance and license.
- **Privacy and rights:** Do not send patient data, unpublished data, confidential material, or copyrighted full-text figures to third-party tools without authorization. Do not reproduce published illustrations; redraw an original representation from verified relationships.
